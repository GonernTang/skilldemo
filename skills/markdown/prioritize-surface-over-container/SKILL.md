## PRIORITIZE SURFACE OVER CONTAINER

**Process:**
1. Scan visible surfaces (countertops, tables, shelves) for the target object.
2. Confirm exact object name and ID (e.g., "toiletpaper 2" vs "toiletpaper").
3. Only open containers (drawers, cabinets) if surface scan yields no results.
4. Verify proximity before moving items between locations.

**Anti-patterns:**
- Opening all containers sequentially without checking visible surfaces first.
- Confusing distinct locations (e.g., "toilet" vs "toiletpaperhanger").

**Failure Recovery:**
- Re-scan the room for unobserved surfaces.
- Check inventory to see if object was already picked up.
- Try alternative containers known to hold similar items.
