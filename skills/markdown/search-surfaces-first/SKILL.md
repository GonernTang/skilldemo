## SEARCH SURFACES FIRST

**Process:**
1. Scan the immediate view for visible flat surfaces (countertops, tables, shelves, desks).
2. Navigate to each surface and inspect contents using 'look' or 'go to'.
3. Only proceed to open closed containers (drawers, cabinets, fridge) if the object is not found on surfaces.

**Anti-patterns:**
- Opening closed containers immediately without checking visible surfaces.
- Assuming objects are always stored inside closed furniture rather than placed out.

**Failure Recovery:**
- If surface search yields nothing, expand search radius to adjacent rooms.
- If container search fails, re-evaluate if the object name matches known synonyms or hidden locations.
