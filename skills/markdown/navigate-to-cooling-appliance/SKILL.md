## Navigate To Cooling Appliance

**Process:**
1. Identify the target cooling appliance (e.g., fridge).
2. Move to the appliance location explicitly before issuing the cool command.
3. Ensure the appliance is open.
4. Perform the cool action while standing adjacent to the appliance.

**Anti-patterns:**
- Attempting to cool an object from a distance without moving to the appliance.
- Assuming the appliance is open without checking its state first.
