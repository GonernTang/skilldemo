## Do Not Skip Visible Surfaces

**Why it happens:**
The agent assumes objects are stored away and jumps to containers, missing items that are simply sitting on tables, counters, or shelves.

**How to avoid:**
1. Prioritize scanning all visible surfaces (countertops, tables, shelves) before opening containers.
2. If an object is not found on a surface, verify visibility before assuming it is hidden.
3. Use observation logs to track which surfaces have already been cleared.
