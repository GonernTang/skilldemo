## Prioritize Target Search

**Process:**
1. Analyze the task instruction to identify the specific object requiring attention (e.g., Egg, Pot).
2. Scan visible surfaces and relevant appliances (stove, microwave) before opening closed storage.
3. Verify object presence via observation commands before committing to travel.
4. Acquire the object immediately upon discovery to prevent unnecessary navigation loops.

**Anti-patterns:**
- Navigating to the final destination (e.g., Fridge) before securing the target object.
- Opening every available cabinet sequentially without filtering by relevance to the task.
