## SURFACE AND LOCATION VERIFICATION

**Process:**
1. Upon arriving at a location, read the full observation list carefully.
2. Search for the target object name specifically in the visible list.
3. If the object is on a surface, interact directly.
4. If the object is likely inside, verify the container is open before attempting to take.
5. Distinguish between similar named locations (e.g., toilet vs toiletpaperhanger).

**Anti-patterns:**
- Attempting to take from a closed container without opening it first.
- Confusing distinct location IDs (e.g., treating a hanger as a toilet).

**Failure Recovery:**
- If interaction fails, re-evaluate the observation list to confirm object presence and location accuracy.
- Check if the container requires an 'open' action before access.
