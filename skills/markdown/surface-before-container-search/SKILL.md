## SURFACE BEFORE CONTAINER SEARCH

**Process:**
1. Navigate to the room containing the target object.
2. Observe all visible flat surfaces (countertops, shelves, tables, beds).
3. If the object is not found on surfaces, proceed to open containers (drawers, cabinets).
4. Verify container contents before assuming the object is elsewhere.

**Anti-patterns:**
- Opening drawers or cabinets immediately without checking the top surfaces first.
- Assuming an object is inside a container without visual confirmation or prior knowledge.

**Failure Recovery:**
- If a container is empty, close it and return to checking nearby surfaces.
- If multiple containers fail, expand the search radius to adjacent rooms or furniture.
