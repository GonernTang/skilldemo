## Verify Object State and Location

**Process:**
1. Navigate to the target location.
2. Read the observation to confirm the specific object exists and is visible.
3. Check the state of any required containers (e.g., open doors/drawers) before interaction.
4. Only proceed with the action if the object is confirmed present and accessible.

**Anti-patterns:**
- Assuming an object is available without reading the observation list.
- Attempting to interact with closed containers without opening them first.
