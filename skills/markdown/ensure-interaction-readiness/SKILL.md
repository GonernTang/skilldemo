## Ensure Interaction Readiness

**Process:**
1. Identify the target object or location required for the current action.
2. Navigate directly to the specific location where the action must occur.
3. Verify the state of the target (e.g., ensure containers are open or closed as required).
4. Execute the interaction action only after confirming readiness.

**Anti-patterns:**
- Attempting to perform an action (like cleaning or heating) while standing far away from the target.
- Ignoring container states, such as trying to access items inside a closed cabinet or drawer.
